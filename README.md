# Discord-Image-Classification-Bot

## 📌 Deskripsi
Bot Discord berbasis Python yang menggunakan model AI dari **Google Teachable Machine** untuk mengklasifikasikan gambar.  
Pengguna cukup mengunggah gambar ke server Discord, lalu bot akan memberikan hasil prediksi secara otomatis.

## ⚙️ Cara Kerja
1. Model dilatih di Teachable Machine sesuai dataset (misalnya ekspresi wajah, jenis makanan, atau sampah).
2. Bot menerima gambar dari pengguna.
3. Model melakukan klasifikasi dan mengembalikan hasil prediksi ke Discord.
